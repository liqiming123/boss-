# 安全

系统执行数据最小化：不保存招聘平台密码、Cookie、完整 HTML、简历或不必要的评价。URL 只保存 SHA-256；诊断字段有白名单。唯一的聊天内容例外是经业务负责人明确授权后，仅截取当前候选人的聊天滚动区域并流式上传到受限飞书多维表格。API 不持久化图片字节；日志不得包含图片、简历、聊天正文或带签名的来源 URL。

点击查重命中时只保存提醒幂等所需的公司、双方招聘者、候选人身份摘要、规范化岗位、证据等级、命中次数和时间；候选人姓名仅存在待发送通知载荷中，发送成功后立即清空。点击阶段不创建候选人来源、跟进、招聘事件、正式冲突或候选人飞书行。

生产环境的身份来自飞书 OAuth。管理后台不提供邮箱密码登录，授权成功后由服务器设置不可被前端 JavaScript 读取的 `HttpOnly` 会话 Cookie；用户无需查看、复制或管理任何令牌。扩展为了在页面重开和断网后续传，内部使用独立、可撤销的设备凭据；扩展不显示该凭据，服务器仅保存其哈希。服务器只保存飞书 `open_id`、`user_id`和显示名，不保存飞书个人访问令牌。插件业务接口必须验证活动设备，并校验该设备招聘者与 BOSS 页面招聘账号的绑定。BOSS 右上角姓名只用于账号映射，不能充当登录凭据。开发环境保留本地测试兼容路径，`APP_ENV=production` 时自动关闭。

候选人字段只作为待同步/重试缓存。飞书同步成功后立即清空 Outbox 载荷；超过缓存期且已存在飞书记录的候选人来源会删除姓名、年龄、工作年限、学历、平台 ID、页面摘要和状态文本，只保留身份签名、会话岗位幂等键、飞书记录 ID、时间、水位、附件令牌和必要状态。诊断、事件、审计和失败载荷按环境变量设定期限清理。

生产配置采用启动失败保护：禁止默认密钥、SQLite、Mock 飞书、HTTP 公网回调或缺失公司/飞书表配置。截图在上传飞书前完成设备归属、关联来源、类型、大小和哈希校验；API 不保存文件字节。

生产要求 HTTPS、严格 CORS、强密钥、PostgreSQL 最小权限、日志脱敏、依赖扫描、备份加密和定期权限审计。扩展仅在用户保存服务器地址时申请该 HTTPS Origin 的访问权限；插件消息路由使用显式白名单，不从远程加载可执行代码。
